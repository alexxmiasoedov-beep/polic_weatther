# polic_weatther

Мониторинг рынков «Highest temperature in …» (Polymarket + Kalshi) по семи
городам: Атланта, Остин, Хьюстон, Лос-Анджелес, Майами, Сиэтл,
Сан-Франциско — и ежедневный прогноз победившей корзины Polymarket.

## Как это работает

- **Каждый час в :05** (начиная с 19:05 по Минску накануне дня рынка)
  GitHub Actions запускает `collector.py`: цены всех корзин обеих площадок
  по целевой дате пишутся строкой в `data/<дата>.jsonl` и коммитятся.
- **Ежедневно в 19:20 по Минску** запускается Claude-сессия (Routine):
  свежий снапшот, `analyze.py` по завершившемуся дню, самостоятельный
  анализ движения цен и отправка прогноза в Telegram
  (@polic_weather_bot): город → корзина → вероятность → текущая цена.
  Прогноз сохраняется в `forecasts/`.

## Файлы

| Файл | Назначение |
|---|---|
| `config.py` | города, серии Kalshi, правило целевой даты (граница суток 19:05 Минска) |
| `collector.py` | почасовой снапшот цен |
| `analyze.py [дата]` | сводка дня: траектории, перенос Kalshi→PM, базовый прогноз |
| `notify.py` | отправка в Telegram (токен — env `TELEGRAM_BOT_TOKEN`) |
| `data/` | собранные снапшоты, по файлу на дату рынка |
| `forecasts/` | ежедневные прогнозы и учёт попаданий |
| `history/manual_history.json` | ручная история 21–27.08.2026 (из `docs/weather_markets_monitor.xlsx`) |

Подробная логика анализа — в `CLAUDE.md`.
